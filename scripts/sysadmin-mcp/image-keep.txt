# image-keep.txt - image tags the sysadmin reclaim must NEVER remove (docker_reclaim.py).
#
# One glob pattern per line, then `#` and the reason. A pattern is matched (case-sensitive,
# Python fnmatch; `*` also crosses `/`) against the image's normalised `repo:tag` - the form
# `docker images` prints, with `docker.io/` and `docker.io/library/` dropped and `:latest`
# added when no tag is given. Blank lines and lines starting with `#` are ignored.
#
# A tag that matches protects its whole IMAGE ID: no other tag of the same id is removed
# either (removing a sibling tag would free nothing and would leave the id one step from
# deletion). If this file is missing or unreadable, reclaim removes NO tagged image at all.
#
# Seeded 2026-09-27 (ac-sysadmin-reclaim) from `docker images` on the ai-stack host; the
# tags each line protected on that day are listed in the item's dev-run evidence.

*-prev-*                        # previous-deploy rollback tags (*:local-prev-<date>)

*:pre-*                         # named pre-change rollback tags (openbrain-curator:pre-..., openbrain-mcp-server:pre-..., openbrain-research:pre-...)
*:backup-*                      # named backup tags (openbrain-mcp-server:backup-...)
